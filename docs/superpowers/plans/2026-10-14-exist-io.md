# exist.io — Origin-Compatible Git Forge Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `exist.io` — a self-hosted git forge (repositories, pull requests, checks, webhooks) that is wire-compatible with the Cursor Origin public API, so Origin clients (CLI, MCP, Apps, Terraform provider) work unchanged against it.

**Architecture:** Go backend exposing the Origin REST surface (`/v1/origin/*`) with an OpenAPI 3.1 spec generated from the same proto definitions. Git storage via `go-git` (pure Go, no cgo). Auth replicating Origin's three credential types (app JWT, `oit_` install token, user token) + the 25-scope catalog. An MCP server and an `origin`-compatible CLI as thin clients.

**Tech Stack:** Go 1.23+, `go-git/v6`, `connectrpc`, `sqlite` (metadata) + `git` (object store), OpenAPI 3.1 via `protoc-gen-openapi`.

**Spec:** Reverse-engineered from the Origin OpenAPI 3.1 spec (`cursor.com/docs/api/origin/openapi.yaml`), the open-source Terraform provider, and the Rust CLI binary. Reference evidence: `/tmp/opencode/origin-spec/openapi.yaml`, `/tmp/opencode/tfcursor/`, `/tmp/opencode/origin-bin/co`.

### Auth model
- **Three token types:** `app` (Ed25519 JWT), `installation` (`oit_…`, ≤15 min), `user` (OAuth user credential).
- **Token exchange:** raw `key_`/`crsr_` API key → `POST {endpoint}/auth/exchange_user_api_key` → `{accessToken, refreshToken}`.
- **Scopes (25):** `app:metadata:read|write`, `app:webhook_deliveries:read|write`, `app:settings:write`, `installation:metadata:read`, `namespace:apps:read|create`, `namespace:installations:write`, `namespace:settings:read|write`, `namespace:repositories:read|create`, `namespace:user_tokens:write`, `repository:metadata:read`, `repository:settings:write`, `repository:contents:read|write`, `repository:pull_requests:read|write`, `repository:pull_requests:reviews:read|write`, `repository:checks:read|write`, `repository:members:read`, `repository:rulesets:read|write`, `repository:mirror:sync`.
- **x-origin-scopes extension** on every operation: `tokenTypes`, `scopes`, `ambient`, `installationScopes`.
- **Admin APIs:** `GET https://api.cursor.com/teams/members` (Basic, resolves `user_email`→`user_…`), `GET https://api.cursor.com/organizations/groups?name=` (Basic, resolves `group_name`→`grp_…`).

### Key entities & enums
- **Repo:** `id` (`repo_…`), `name`, `fullName`, `owner{slug,id,type}`, `defaultBranch`, `cloneUrl`, `mirror{source,sourceId,status}`, `visibility`(internal|private), `allowMergeCommit`, `allowSquashMerge`, `deleteBranchOnMerge`.
- **Owner/Namespace:** `slug`, `id` (`ns_…`), `type`(user|team).
- **Grant:** `user{user_…}` | `group{grp_…}` | `teamGroup{members|admins}` + `permission`. Repo: `read|write|admin|custom`. Namespace: `read|contributor|write|admin|custom` (sent as `PERMISSION_READ` etc.).
- **Ruleset:** `enforcement`(active|evaluate|disabled), `kind`(merge_branch|push_branch|push_tag|push_repository), `rules[]` (ruleType + parameters), `bypassActors[]`.
- **PullRequest:** `id`(`pr_…`), `number`, `state`, `draft`, `merged`, `title`, `body`, `head`/`base` (PullRequestRef), `author`, `labels`, `mergeCommitSha`, `autoMerge` (PREVIEW).
- **CheckRun:** `id`(`cr_…`), `status`(queued|in_progress|completed|rerequested), `conclusion`(success|failure|neutral|cancelled|timed_out|action_required|stale|skipped).
- **Webhooks:** 35 event types. Signature: Ed25519 `v1ed` over `SHA256({webhook-id}.{webhook-timestamp}.{body})`. Verify against `/v1/origin/keys`.
- **MCP:** 33 tools, stateless streamable HTTP at `/mcp` and `/mcp/readonly`.

### CLI command surface (origin, Rust)
`origin app create|edit|list|view|webhook deliveries|ping|redeliver`, `origin pr list|view|checks|thread list`, `origin repo list|view|edit|mirror status|sync|transition|force-cutover|detach`. Config via `CURSOR_ORIGIN_ENDPOINT`, `CURSOR_API_KEY`, `CURSOR_AUTH_TOKEN`, `ORIGIN_REPO`, `ORIGIN_TIMEOUT_MS`. Headers: `x-cursor-client-type`, `x-cursor-client-version`, `x-cursor-team-id`.

## Global Constraints

- All routes MUST be under `/v1/origin/` and match Origin's path shapes exactly (including `:action` verbs like `:syncMirror`, `:entries:replace`, `:grep`, `:batchGet`).
- All IDs MUST use Origin prefixes: `app_`, `inst_`, `ns_`, `repo_`, `pr_`, `cr_`, `crg_`, `cra_`, `nsca_`, `nsip_`, `whd_`, `wha_`, `evt_`, `grp_`, `user_`, `stk_`, `oit_`.
- All enums MUST use Origin's exact wire values (e.g. `PERMISSION_READ`, `PERMISSION_CONTRIBUTOR`).
- Auth MUST accept all three token types and enforce the 25-scope catalog.
- OpenAPI spec MUST be 3.1 and generated from proto (matching Origin's `protoc-gen-openapi` output).
- Every error response MUST use Origin's `Status` envelope: `{code, message, details}`.
- Test files MUST use Go's standard `testing` + `httptest`; no external test framework.
- No cgo. Pure Go (`go-git/v6`).
- Commit messages MUST follow `feat:` / `fix:` / `test:` / `chore:` conventional commits.
