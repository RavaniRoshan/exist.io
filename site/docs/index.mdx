exist.io is an open-source, self-hosted Git forge built for software engineering teams and autonomous AI coding agents. It provides a reliable home to host code, collaborate through pull requests and reviews, enforce enterprise security rulesets, and connect coding agents through dedicated, permission-aware interfaces.

The goal is simple: keep your repositories, collaboration history, and agent integrations on infrastructure you control.

:::note[Self-hosted & agent-native]
exist.io runs entirely on your own hardware or cloud instances with zero proprietary cloud dependencies.
:::

## Core capabilities

- **Your repositories:** Own your data, Git packfiles, and SQLite database with zero external vendor lock-in.
- **Dual Git transports:** Pure-Go Smart-HTTP and native SSH server on port `2222` with zero host daemon requirements.
- **Cryptographic verification:** Real-time OpenSSH SIGSPEC and GPG commit signature audits in the Web UI.
- **Agent integrations (MCP):** Embedded Model Context Protocol server at `/mcp` with a read-only sandbox at `/mcp/readonly`.
- **Policy & compliance:** Branch and tag rulesets, bypass actor hierarchies, status check enforcement, SSH CAs, and CIDR allowlists.

## Experimental modules (frozen for launch)

These modules are implemented and tested, but frozen for launch and not part of the supported surface:

- **Git LFS v1:** CAS storage and the file-locking protocol (`/info/lfs/locks`).
- **Enterprise federation:** OIDC and SAML 2.0 SSO plus SCIM 2.0 user sync. The SSO callback fails closed with HTTP 501 in this build.
- **Infrastructure as Code:** Terraform/OpenTofu provider and Kubernetes Helm chart, provided as source in `deploy/` without support.

## Getting started quickly

Install `existd` and the `exist` CLI in seconds (Linux, macOS, Windows):

```bash
curl -fsSL https://raw.githubusercontent.com/RavaniRoshan/exist.io/main/scripts/install.sh | bash
```

Then initialize storage and launch your forge daemon:

```bash
# Initialize storage and primary administrator
existd bootstrap --email admin@example.com --namespace acme --data-dir ./data

# Start the forge daemon (Smart-HTTP :8080, SSH :2222, MCP :8080/mcp, Web UI)
existd
```

Or build from source with zero CGO dependencies:

```bash
go build -o bin/existd ./cmd/existd
./bin/existd bootstrap --email admin@example.com --namespace acme --data-dir ./data
./bin/existd
```

Follow the full [Getting Started guide](/getting-started) to configure remotes, connect coding agents, and use the companion CLI.
