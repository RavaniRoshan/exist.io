exist.io is an open-source, self-hosted Git forge built for software engineering teams and autonomous AI coding agents. It provides a reliable home to host code, collaborate through pull requests and reviews, enforce enterprise security rulesets, and connect coding agents through dedicated, permission-aware interfaces.

The goal is simple: keep your repositories, collaboration history, and agent integrations on infrastructure you control.

:::note[Self-hosted & agent-native]
exist.io is wire-compatible with Origin forge interfaces while running 100% self-hosted on your own hardware or cloud instances with zero proprietary cloud dependencies.
:::

## Core capabilities

- **Your repositories:** Own your data, Git packfiles, and SQLite database with zero external vendor lock-in.
- **Git Smart-HTTP transport:** Standard `git clone`, `git fetch`, and `git push` over HTTP with token and credential-helper authentication.
- **Human & agent collaboration:** Pull requests, 3-way merge engine, inline review threads, emoji reactions, and labels.
- **Agent integrations (MCP):** Embedded Model Context Protocol server exposing 34 specialized tools at `/mcp` and sandboxed `/mcp/readonly`.
- **Policy & compliance:** Branch and tag rulesets, bypass actor hierarchies, status check enforcement, SSH CAs, and IP allowlists.

## Getting started quickly

exist.io compiles to a single self-contained binary without cgo. You can initialize a new forge, create an administrative workspace, and start serving Git repositories and agent workflows in minutes:

```bash
# Build the server daemon
go build -o bin/existd ./cmd/existd

# Initialize storage and primary administrator
./bin/existd bootstrap --email admin@example.com --namespace acme --data-dir ./data

# Start the forge daemon
./bin/existd
```

Follow the full [Getting Started guide](/getting-started) to configure remotes, connect coding agents, and use the companion CLI.
