title: Model Context Protocol (MCP) tool catalog
description: Complete technical reference of all 34 MCP tools exposed by exist.io for AI coding agents.
---

exist.io exposes **34 specialized tools** over the [Model Context Protocol](https://modelcontextprotocol.io) at `/mcp` (read-write) and `/mcp/readonly` (sandboxed read-only).

Every tool call uses standard JSON-RPC 2.0 with method `tools/call`.

---

## 1. Repository & Git Navigation (10 tools)

| Tool Name | Scope | Parameters | Description |
| :--- | :--- | :--- | :--- |
| `repo_get` | Read | `owner` (string), `repo` (string) | Retrieve repository details, default branch, and visibility. |
| `repo_list` | Read | `owner` (string), `limit` (int, opt) | List repositories within a namespace. |
| `repo_tree` | Read | `owner` (string), `repo` (string), `ref` (string, opt), `recursive` (bool, opt) | Recursively inspect file trees at a specified commit, branch, or tag. |
| `file_read` | Read | `owner` (string), `repo` (string), `path` (string), `ref` (string, opt) | Read the content, encoding, and byte size of a file blob. |
| `commit_get` | Read | `owner` (string), `repo` (string), `sha` (string) | Get commit metadata, author, committer, and parent hashes. |
| `commit_list` | Read | `owner` (string), `repo` (string), `ref` (string, opt), `limit` (int, opt) | List commits reachable from a reference. |
| `branch_list` | Read | `owner` (string), `repo` (string) | List all branches in the repository with target commit SHAs. |
| `diff_compare`| Read | `owner` (string), `repo` (string), `base` (string), `head` (string) | Compute two-way and three-way diffs between two refs or commits. |
| `tag_list` | Read | `owner` (string), `repo` (string) | List all tags in the repository. |
| `ref_resolve` | Read | `owner` (string), `repo` (string), `ref` (string) | Resolve symbolic ref (such as `HEAD` or branch name) to an exact SHA. |

## 2. Pull Request Management (8 tools)

| Tool Name | Scope | Parameters | Description |
| :--- | :--- | :--- | :--- |
| `pull_request_create` | Write | `owner`, `repo`, `title`, `base`, `head`, `body` (opt) | Open a new pull request between `head` and `base` branches. |
| `pull_request_get` | Read | `owner`, `repo`, `number` (int) | Retrieve pull request details, state, and mergeability verdict. |
| `pull_request_list` | Read | `owner`, `repo`, `state` (string, opt: `open`\|`closed`\|`all`) | List pull requests for a repository. |
| `pull_request_update` | Write | `owner`, `repo`, `number`, `title` (opt), `body` (opt) | Update pull request title or description. |
| `pull_request_merge` | Write | `owner`, `repo`, `number`, `method` (string: `merge`\|`squash`), `commit_message` (opt) | Merge a pull request through policy rulesets. |
| `pull_request_close` | Write | `owner`, `repo`, `number` | Close an open pull request without merging. |
| `pull_request_files` | Read | `owner`, `repo`, `number` | List all modified, added, and deleted files in a pull request. |
| `pull_request_diff` | Read | `owner`, `repo`, `number` | Retrieve the unified diff patch for a pull request. |

## Read-Only Sandbox Policy

When connecting to `http://<host>:<port>/mcp/readonly`:
- All **Read** tools operate normally.
- All **Write** tools immediately return error code `-32001` (Unauthorized) with message:
  ```json
  {
    "jsonrpc": "2.0",
    "id": 1,
    "error": {
      "code": -32001,
      "message": "Tool '<tool_name>' is not permitted on read-only MCP endpoint"
    }
  }
  ```
