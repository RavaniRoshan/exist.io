exist.io has completed its foundational core milestones and provides a fully functional, self-hosted Git forge and agent platform.

## Implemented & verified capabilities

All components below are backed by automated unit, contract, and integration tests across 14 Go packages with 100% test pass rates:

### 1. Server daemon & storage foundation
- **Binary Daemon:** Standalone `existd` binary with graceful shutdown and configurable logging.
- **Offline Bootstrap:** Safe, one-time bootstrap command (`existd bootstrap`) provisioning SQLite WAL database, default namespace, and root administrator credentials.
- **Storage Engines:** Pure-Go SQLite metadata store (`modernc.org/sqlite`, zero cgo) and `go-git/v6` bare repository packfile storage.

### 2. Git Smart-HTTP transport
- Standard Git HTTP transport (`info/refs`, `git-upload-pack`, `git-receive-pack`).
- Full support for `git clone`, `git fetch`, and `git push`.
- Integrated token authentication and namespace/repository permission checks.

### 3. REST API surface (119 operations)
- **100% coverage** of the 119 Origin REST API operations.
- Full CRUD for namespaces, repositories, branches, commits, trees, blobs, diffs, and tags.
- Pull request lifecycle: creation, updates, state transitions (`open`, `closed`, `merged`), auto-merge queues.
- Collaboration features: line-level review threads, general comments, emoji reactions, and label management.
- Dynamic OpenAPI 3.1 specification publication at `/v1/origin/openapi.yaml`.

### 4. Model Context Protocol (MCP) server
- First-class JSON-RPC 2.0 MCP server mounted at `/mcp`.
- **34 specialized agent tools** covering tree traversal, blob reads, branch management, pull request creation, inline commenting, and status checks.
- Read-only sandbox mount at `/mcp/readonly` to safely execute unvetted agents.

### 5. Policy, merge engine & security
- Native 3-way merge and squash merge engine with conflict detection.
- Ruleset policy evaluator supporting branch and tag protections, required review counts, passing check runs, and bypass actor lists.
- Check suites and check runs API for reporting CI/CD and agent test results.
- Inbound IP allowlists with CIDR block filtering.
- SSH Certificate Authority key management.
- Ed25519 signed webhooks and delivery logs.
- GitHub mirror configuration and status tracking.

### 6. Exist CLI
- Companion command-line binary (`exist`) in `cmd/exist`.
- Subcommands: `auth`, `repo`, `pr`, `app`, and `api`.
- Supports positional argument reordering and agent-friendly output modes.

### 7. Official Infrastructure as Code (IaC)
- Production-ready Terraform/OpenTofu provider (`deploy/terraform-provider-exist`) and Helm chart (`deploy/helm/exist-enterprise`).

### 8. Embedded Pure-Go SSH Server (:2222) & Git LFS CAS Engine
- Standalone zero-cgo SSH server listening on port 2222 with deploy key isolation and repository UUID verification.
- Content-Addressable Storage (CAS) with SHA-256 validation and streaming chunked uploads for large binary assets.

### 9. Cryptographic Commit Signature Verification
- Real-time OpenSSH SIGSPEC and GPG (RFC 4880) commit signature parsing and public key fingerprint matching.

### 10. SCIM 2.0 User Lifecycle & Enterprise SSO
- RFC 7644 SCIM user sync at `/scim/v2/Users` with automated provisioning and immediate deprovisioning.
- OpenID Connect (OIDC) and SAML 2.0 Single Sign-On federation.

### 11. Pixel-Accurate GitHub Primer Web UI
- Built on Vite, React 19, and Tailwind CSS with 6px squircle radius and OKLCH color token architecture.
- User profile with contribution heatmaps, global activity feeds, issues, and releases.

### 12. Ephemeral Capability Leases & Autonomous Reviewer
- Short-lived HMAC-SHA256 capability tokens (`pkg/agentlease`) with ref-prefix isolation (`refs/heads/agent/*`).
- Automated PR review agent (`internal/agentreviewer`) with AST symbol search (`internal/symbolsearch`).

### 13. High Availability Consensus & Object Sharding
- Pure-Go Raft consensus state machine (`internal/raftcluster`), automated snapshot replication (`internal/replication`), and distributed object sharding (`internal/objectshard`).

### 14. Code Review Pipeline, Notifications & Migration Wizard (v0.6.0)
- Interactive diff viewer with line commenting, side-aware comment placement, and conversation thread resolution.
- 1-click suggestion application committing code changes directly to PR branches.
- Event-driven auto-merge engine (`AutoMergeEngine`) with PR mutex locking.
- In-app notification center and pure-Go SMTP delivery queue with Primer HTML email templates.
- Multi-platform repository migration wizard cloning Git repositories and importing issues, PRs, and comments.
