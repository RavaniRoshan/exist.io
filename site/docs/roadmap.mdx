exist.io has progressed from an early design concept to a fully functional, self-hosted Git forge and agent platform. This roadmap highlights what has been completed and what lies ahead.

## Completed milestones

### 1. Server daemon & storage foundation (Complete)
- Standalone `existd` daemon with pure-Go SQLite WAL metadata storage and `go-git` packfiles.
- Offline `bootstrap` command to initialize the database and root administrator credentials.
- Graceful shutdown, configurable ports, and health probes (`/healthz`).

### 2. Authenticated Git Smart-HTTP (Complete)
- Standard Git HTTP transport (`info/refs`, `git-upload-pack`, `git-receive-pack`).
- Support for `git clone`, `git fetch`, and `git push` with bearer token or credential-helper authentication.

### 3. Complete REST API (119 operations) & local identity (Complete)
- 100% wire coverage of the 119 Origin REST API operations.
- Full CRUD for namespaces, repositories, branches, commits, trees, blobs, diffs, and tags.
- Dynamic OpenAPI 3.1 specification publication at `/v1/origin/openapi.yaml`.

### 4. Pull requests, reviews & 3-way merge engine (Complete)
- Native 3-way merge and squash merge logic with conflict detection.
- Pull request lifecycle management (`open`, `closed`, `merged`), review approval gates, and auto-merge queues.
- Line-level review threads, general comments, emoji reactions, and label assignment.

### 5. Policy rulesets & enterprise security (Complete)
- Branch and tag rulesets, bypass actor hierarchies, and required status checks.
- Inbound IP allowlists with CIDR block filtering.
- SSH Certificate Authority management and Ed25519 webhook signatures.

### 6. Agent integrations (MCP) & Exist CLI (Complete)
- First-class Model Context Protocol (MCP) server exposing 34 specialized tools over JSON-RPC 2.0 at `/mcp` and `/mcp/readonly`.
- `exist` companion CLI for managing repositories, pull requests, apps, and credentials.
- Terraform provider compatibility for Infrastructure as Code management.

---

## Future horizons

### 7. Visual Web Dashboard
- A responsive browser web UI for viewing repositories, syntax-highlighted file browsing, split diffs, and interactive pull request reviews.
- Organization settings, member management, and audit log dashboard.

### 8. Native SSH server transport
- Embedded SSH server allowing developers to clone and push via `git@host:namespace/repo.git` using standard SSH keys.

### 9. High-availability clustering & enterprise federation
- Multi-node data replication and distributed worker queues for large-scale enterprise deployments.
