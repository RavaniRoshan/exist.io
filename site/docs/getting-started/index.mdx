## Not ready to install yet

There is no supported installation or deployment path today. The current server entry point is still a development scaffold and does not yet compose the repository API into a complete forge.

We will publish setup steps when a fresh installation can reliably:

1. Start against a new data directory without external service credentials.
2. Create its first administrator and namespace through a safe one-time bootstrap.
3. Persist metadata and repository data across restarts.
4. Clone, fetch, and push using authenticated Git-over-HTTP.

Until then, treat this project as under active development rather than a service to deploy with important repositories.
